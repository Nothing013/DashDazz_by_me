Rainbow, Breathe, Solid, and Dual Ring with Hardware Split, Spin, Police Siren, Alternate, Beat Rainbow and Split Beat.

Modes dance to your music with automatic beat detection, band tracking, and auto sensitivity. Oscilloscope and tuning included.

6 palettes, 8 presets, unlimited custom presets, full speed / brightness / saturation / hue control.

Get the app

  1. Download the APK above (or pick a version on the Releases page).
  2. Already installed? Use Settings → About → Check for updates in the app. It checks once a day and verifies the download is signed with your existing key.
  3. Install it (allow install from unknown sources when asked).
  4. Open DashDazz and grant access: Root for full features, or start Shizuku for basic modes.
  5. Pick a mode, tune colors, turn the ring on.

Build it yourself

./gradlew :app:assembleDebug needs no secrets. Release builds need the signing key (see readme).
